# 回声 · Echo

一个逼你开口的英语口语练习软件，每节课 25 分钟，跑在你自己的 Mac 上。

市面上的口语 App 大多在点选、认词、刷题。回声反过来：**每一步都要你说出来，每次开口都自动录音存档，进步只看录音和真实指标**（语速、填充词、连贯语段长度），不做打卡天数、"流利度 74%" 这类数字。

## 新课程：从 3000 节倒数（Rebirth）

「今天」页是一条从发音和最简单的句子开始、逐级往上的口语课程，目标是把英语练成能不假思索说出来的第二语言。原来照着雅思范例跟读的课程挪到了「雅思跟读」页，照样能用。

- **倒计时 3000 节**：数的是做完的节数，不是天数。断了不清零，没有连续打卡；主数字是离下一个里程碑（每 30 节）还有几节。
- **一节 25 分钟，五段都要开口**：回忆（看中文说出旧句子）→ 声音（一个韵律或音位点）→ 新句（看中文先自己说，再看英文）→ 用（和 AI 角色扮演，用当天的句型办成一件事）→ 快（60 秒把刚才的事讲一遍，看语速和停顿）。用当天的句型说出 2 个新句子，这一节才算做完。
- **定位测试**：六级，看中文提示直接开口，按意思对不对和多快开口判分，找出「张口就来」在哪一级断掉，决定从哪学起。
- **阶段 1 大纲**：120 节，每节一个句型、一个能做到的事，按定位测出的弱项排在前面反复出现；每 10 节一节综合课，把这一块的句型混着用。现在写好了前 20 节，后面陆续量产。大纲见 [`docs/rebirth/syllabus-stage1.md`](docs/rebirth/syllabus-stage1.md)。
- **卡住了也有办法**：句子里的词点一下查词典，「拆句」看句子结构和可迁移的句型；对话里说不出来可以写中文（开了 DeepSeek 语音识别还能直接用中文说）问怎么说。
- **纠错先提示**：AI 先用中文指出哪里不对，让你自己改了再说一遍，改不出来才给答案；改过的句子进语块本，之后在回忆段出现。
- **课程内容的检查**：句子以最常用的 721 个口语词（NGSL-Spoken）为主，情境离不开的词（pharmacy、medium 这类）单独标出、每节不超过几个；新句型在后面几节里一定再说一次；每节由程序查格式、词表和复现，再由另一个模型逐句审自然度。

## 其他练习

- **雅思跟读**：IELTS 口语范例逐句跟读，每句一个练习重点（连读、重音、语调或断句），语调曲线和原声对比；每天一节约 15 分钟，热身复述、跟读、语块、开口说、到期复习。
- **今日语块**：从 BBC *The English We Speak* 学一个地道说法，马上用它说一句你自己的话。
- **开口说**：不看稿就本课话题说 1–2 分钟。点评前先按提示自己改对一处、说出来，再看「你说的 vs 母语者会怎么说」。不给分数。
- **4/3/2 复述、自言自语**：同一段内容限时 4、3、2 分钟连说三遍，第 3 遍里值得换个说法的句子做成卡片；60 秒不停说、看图描述、睡前复述今天。
- **名词说法**：精析和开口说点评会标出「中文用动词、英语用名词」的说法（我决定了 → make a decision），进语块本；复习时只给动词式的中文，你用名词说法说出来。日常（take a break）和工作（an increase in）分开记。
- **语块本、错误本**：开口式间隔复习（看中文说整句，Whisper 判对错）；个人错误同时最多盯 5 条，48 小时复检，说对就毕业。
- **发音**：发音体检找出你分不清的音，生成专属的最小对立对，先听辨再跟读。
- **AI 对话**：聊课程话题，演练组会汇报、被追问方法、给外行讲概念，或点餐、问路等日常场景。每个场景有一个任务，结束时判定完成没有；对话中不打断，会标出你有没有反问对方、接对方的话。
- **进步**：最近 7 天小结（练了几天、指标和错误比上周多还是少）、「做到的事」（每件配当时的录音）、自由说话里用出的语块；所有录音和指标曲线；同一道题的基准录音，第 1 次和现在并排听。
- **我的素材**：导入你自己的英语音频（播客、课本录音、视频都行），本机生成逐句字幕后，和每天的课一样逐句跟读。
- 点词查词（离线词典）、语块导出到 Anki。

## 需要什么

- **Apple 芯片的 Mac**（M1 及以后），macOS 12 以上。语音转文字用本机 Whisper（MLX），不联网。
- 约 5GB 磁盘：Whisper 模型约 1.6GB，雅思课程音频约 1GB，词典约 150MB，再加 Python 环境。
- Chrome 浏览器（也可以自己打包成 Mac App，见下文）。
- **DeepSeek API key（必需）**：句型讲解、点评和 AI 对话都靠它。在 [platform.deepseek.com](https://platform.deepseek.com) 注册、充值几块钱、创建 key。按量付费，每天练 15 分钟大约 ¥0.1–0.3。也可以改用智谱 GLM。
- **阿里云百炼 API key（可选）**：朗读示范句用百炼的 Qwen-Audio 语音合成（每句只合成一次，存在本机），不填就用系统自带的声音；「AI 听发音」用 Qwen-Omni 听你的录音点评发音。不填，其他功能照常用。
- **DeepSeek 语音识别（可选，设置里打开）**：短句识别从本机的约 4 秒降到 1–2 秒，也能识别中文；失败时自动退回本机 Whisper。

**Windows 版**在 [`windows/`](windows/) 文件夹，安装方法见[那里的 README](windows/README.md)。

## 安装

**最省事的办法**：复制本仓库的网址 https://github.com/Lucas0ng/echo-speaking 发给豆包，打开「工作模式」，让豆包帮你在本地部署。想自己动手，照下面的步骤。

1. 下载代码：

   ```bash
   git clone https://github.com/Lucas0ng/echo-speaking.git
   ```

   也可以在本页点 **Code › Download ZIP** 后解压。用 ZIP 的话，第一次要**右键点 `start.command` › 打开**（macOS 会先拦一下网上下载的脚本）。

2. 双击 **`start.command`**。第一次会装好 uv 和 Python 依赖（几分钟，只需一次），然后浏览器自动打开 http://127.0.0.1:8765 。
3. 双击 **`下载课程.command`**：从官方播客源下载课程音频（约 1GB，可以中途关掉，下次接着下）和离线词典。下完后关掉 start.command 的窗口，再双击它重新打开。

   在中国大陆，BBC 的播客源一般要开代理才能下。BBC 没下到也能用：每课只是少了「今日语块」这一步，跟读和开口说照常。一节课都没下到的话，可以先在「我的素材」里用自己的音频练。
4. 照「今天」页顶部的「开始使用」清单做：填 API key、允许麦克风、录一段基准录音。

第一次转写时会自动下载 Whisper 模型；连不上 Hugging Face 时自动改用 hf-mirror.com 镜像。课程的逐句字幕会在你不练习的时候后台逐集生成。

### 打包成 Mac App（可选）

装好 Xcode 命令行工具（`xcode-select --install`）后，在项目文件夹运行 `mac/build.sh`，得到 `dist/回声.dmg`，把「回声」拖进「应用程序」。App 只是窗口外壳，用的还是这个文件夹里的代码和数据，所以打包后不要挪动这个文件夹。App 会自己启动后台服务；服务意外停了，几秒内自动重启，页面不用刷新。

## 用自己的音频

打开「我的素材」页，点「导入音频…」选文件；或者点「在访达中打开文件夹」，把文件拖进去再点「刷新」。文件夹在课程音频文件夹里，叫 `我的素材`。

支持 mp3、m4a、aac、wav、flac、ogg、opus、webm、mp4、mov。本机 Whisper 会在后台给每个文件生成逐句字幕，长音频要几分钟。字幕好了，就能逐句跟读、看句型、点词查词。素材不算进课程编号和进度。

## 数据和隐私

- 进度、录音和转写都存在项目里的 `data/` 文件夹，备份它即可；API key 存在 `config.json`。这两样都在 `.gitignore` 里，不会被提交。
- 语音转文字默认在本机完成。只有用到 AI 功能时，相关文字（「AI 听发音」时是那段录音）才会发给你自己配置的 AI 服务。
- 两项可选的云端服务默认关闭，在设置里打开后才会联网：「DeepSeek 语音识别」会把短句录音发给 DeepSeek（限时独白、基准录音和跟读仍在本机识别）；「百炼语音合成」会把要朗读的英文句子发给阿里云百炼。

## 课程音频
