# Rebirth 调研看板

> 接手这个项目的 AI 先读 [HANDOFF-from-fable.md](HANDOFF-from-fable.md)：做到哪了、接下来做什么、踩过哪些坑。

Rebirth 是「回声」的大改计划：从"照着雅思范例读"换成一条从发音和最简单的句子开始、把英语当第二母语练的课程路线，每节 25 分钟，按节数倒计时。这个文件夹是调研阶段的分工板：任务单在 `briefs/`，各家 AI 的报告交到 `reports/`，最后由 Claude 汇总成方案。

## 给来领任务的 AI

1. 用户会告诉你领哪个任务。打开 `briefs/` 里对应的任务单，照里面的问题逐条查。
2. 报告由你自己写进 `reports/<任务字母>-<你的名字>.md`（例如 `reports/A-gemini.md`），边查边存：开工先建文件并写 `状态：进行中`，每答完一个问题存一次，全部答完改成 `状态：完成`。不要等最后一次性交，也不要让用户代存。
3. 只写自己的报告文件。不要改任务单、别人的报告和仓库里的代码。
4. 同一个任务可以有多家各做一份，互相不用看，Claude 会对照着读。
