# 任务 C：教材与开放数据

分这几块查，每一项给：名称、作者/机构、网址（你实际打开过、能访问的）、内容是什么、适合哪个阶段、版权情况（公共领域 / CC 许可具体是哪一种 / 仅可链接不可搬运）。
1. 发音与音标：系统的免费视频课和网站（例如 Rachel's English、Sounds American、BBC Learning English 的 The Sounds of English 和 Tim's Pronunciation Workshop、赖世雄美语音标、Sounds of Speech (Iowa)、YouGlish、Forvo），以及经典教材（American Accent Training、English Pronunciation in Use、Ship or Sheep、Mastering the American Accent）。给出一份“按顺序学完 44 个音 + 重音节奏语调”的课程链接清单，每个音位最好对应到一个具体视频链接。另外查可用的数据：CMUdict（发音词典）、英语最小对立对词表、中国学习者常见发音问题清单（有来源的）。
2. 词表：NGSL / NGSL-Spoken / NAWL、Oxford 3000 / 5000、GSL、AWL、COCA 口语词频、English Vocabulary Profile（按 CEFR 分级）、ECDICT 里已有的词频字段。哪个最适合“口语优先”的排序，许可是什么，下载地址。
3. 分级的能力描述（can-do）：CEFR 官方 descriptor（Companion Volume 2020 里口语互动和口语产出部分）、Pearson Global Scale of English 的 can-do 列表、Cambridge English Profile、ACTFL。哪个能免费拿到、可以直接当软件里的“关卡清单”。
4. 成体系的教材（从零到高级有完整路线的）：新概念英语、English File / American English File、Interchange、Headway、Side by Side、English Grammar in Use 系列、Pimsleur 的课表结构。只需说明它们各自的编排思路（按语法？按功能？按话题？）和每级学时，哪种编排最适合搬来当口语课的大纲。
5. 可以合法下载、带文本的分级音频：VOA Learning English（美国政府作品，公共领域？核实）、BBC Learning English 各栏目、ESL Pod、LibriVox、Tatoeba（带音频的句子，许可）、Mozilla Common Voice、Elllo、TED（许可）。重点核实哪些能搬进软件、哪些只能链接。
6. 中英对照的句子库（用来做“看中文说英文”的练习）：Tatoeba 中英句对、其他开放平行语料，数量和质量如何。

最后给一份建议：如果只能选一套大纲 + 一份词表 + 一套发音课 + 一个音频来源，你选哪几个，为什么。

## 通用要求

- 你是调研员，只做联网调研和写报告，不要改任何代码。
- 必须真的联网查，把页面内容读过再写。每条结论后面跟你实际打开过的来源链接。打不开或没查到的，明确写“未查到”，不要凭印象编数字、编链接。
- 把“来源原文说的”和“你的推断”分开写。
- 报告用简体中文、Markdown，先给结论再给依据，控制在 2500 字以内，不要套话。

## 学习者画像

母语中文的成年人，阅读还行、听力中等、口语弱；每天只练 25 分钟；长期目标是把英语练到“第二母语”的程度（想说什么张口就来，不经过中文翻译）。自己做了一个 Mac 上的口语练习软件，用本机 Whisper 做语音识别、大模型做点评和对话。

## 交回方式

报告由你自己写进文件，边查边存，不要等全部查完，也不要交给用户代存。

1. 开工第一步：新建 `docs/rebirth/reports/C-你的名字.md`（例如 `C-gemini.md`，路径相对于用户给你的仓库文件夹）。第一行写：调研者、日期、用了什么联网手段；第二行写 `状态：进行中`。
2. 每答完上面的一个问题，就把这一节写进文件并存盘，再去查下一个。中途断了，已经查到的也留得下来。
3. 全部答完后，把结论小结补到文件最前面，第二行改成 `状态：完成`。
4. 只写这一个文件。你确实没有写本机文件的能力时，在回复的第一句话说明，再输出全文。
