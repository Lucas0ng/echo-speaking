# 练口语软件需求简报（给 Claude 的打包版）

> 背景：用户 Lucas，中国研究生，英语能读、口语弱，目标是工作和日常能流利交流，每天可练约 15 分钟。市面上的练口语软件试了很多都不满意，决定自己造一个。本简报 = 用户的原始需求 + 助手（Muse）的补充建议 + 一轮国外社区/研究调研的核心结论。完整调研报告见同目录 `speaking-app-research.md`。

---

## 一、用户的原始需求（用户原话整理）

1. **逐句分析 + 点词词典 + 生词复习**
   - 需要 AI 帮我分析每一句的句型句式，并且告诉我。
   - 我可以点击句子之中的生词，像词典一样直接显示单词的意思。
   - 之后还能复习这些生词。

2. **要有真实的进步感**
   - 我尝试过市面上很多练习口语的软件，但是他们并没有真正让我体会到那种"我的口语真的在一点点的进步"的那种感觉。这是新软件必须解决的核心问题。

3. **用本机英文文献学英语**
   - 我本机有大量的英文文献，我们也可以用文献来学习。

4. **参考国外社区的方法论**
   - 请到国外论坛或者 Reddit 或者 Threads 或者 YouTube 上搜索练习口语的方法和秘诀，分析之后内化到我们的软件之中。（已完成调研，结论见第三节）

## 二、助手的补充建议

### 对需求 1（句型分析）的补充
- 不要只给语法术语，要做成「**你说的 vs 母语者会怎么说**」的对照，标出句子骨架（主谓宾/时态）和**可迁移的句型模板**（如 "I think this method is good because..."），复习时连句型/语块一起复习，而不只是背单词。
- 点词词典卡要有：发音、音标、常用搭配，而且**例句直接用用户刚说的那句话**——在语境里记词。

### 对需求 2（进步感）的补充机制
- **录音存档对比**：定期录同一题目（描述同一张图/聊同一话题），可一键回听第一次 vs 现在。
- **量化曲线**：语速（词/分钟）、填充词（uh/um）次数、平均句长、语法错误率、生词掌握量。
- **每周小结**：AI 用具体话总结，如「这周冠词错误比上周少了 40%」。
- 可做 CEFR 等级估测作参考。

### 对需求 3（文献）的补充
- 文献是**学术口语**的金矿（组会汇报、答辩、和导师讨论），可自动提取 "This suggests that…"、"In contrast…" 这类高频学术句式做句型库，也可做长难句拆解。
- 但日常口语是另一套体系，**学术线和日常线两个模块必须分开**，不要拿论文句子练日常对话。

### 额外建议（用户未提、助手认为关键）
- **先说后看**：每道题先让用户开口说，之后才给参考说法；先给模板再念，练的是朗读不是口语。
- **个人错误本**：自动收集用户反复犯的错（时态、冠词、介词等）生成个人弱点清单，复习优先练弱点，而不是所有人同一套题。
- **发音反馈**：th 音、词重音、连读等逐词标注；只纠语法不纠发音，进步感会打折。
- **15 分钟一节的结构**：约 2 分钟复述昨天的句型 → 8 分钟新内容开口练 → 5 分钟自由对话 + 复习生词；不要做成刷题软件。

## 三、调研结论（Reddit / YouTube / 论坛 / 研究，已内化为设计原则）

### 公认有效的方法
1. **Shadowing 影子跟读**：每句要带一个明确训练意图（某个音/某种语调）并录音对比；无意图的跟读基本是浪费时间。
2. **输出假说（Output Hypothesis）**：软件主体必须是"逼用户开口产出"，点选/识别题再多也没用。
3. **4/3/2 限时复述**：同一段内容分别用 4 分钟、3 分钟、2 分钟讲完；实验中语速可由 86 提升至 127 词/分钟，进步可测。
4. **语块学习（Chunking）**：按整块短语存取（如 "it turns out that…"），而不是逐词拼句。
5. **SRS 开口式复习 + 个人错误日志**：同时追踪的活跃错误 ≤ 5 个，48 小时复检、达标即"毕业"；复习要开口说出来，不是只认脸。

### 进步感机制（对应需求 2）
1. **每月同题录音 A/B 对比**：过去 vs 现在并排听。
2. **真实指标曲线**：语速、每百词填充停顿数——研究显示 1–3 周即可测出变化。
3. **"自发用出"计数**：学过的语块在自由说话中真正自发用出才计入掌握；配合错误消灭曲线。
4. **明确拒绝假进度**：打卡天数、"流利度 74%"式的编造分数不要做。

### 文献学口语
- 玩法：句型提取、文献句复述、术语点读、学术短语库。
- 局限：学术英语 ≠ 日常口语，两条线分开（与第二节判断一致）。

## 四、一句话总结给开发者

做一个以"**逼开口产出 + 逐句句型/语块分析 + 点词词典与 SRS 复习 + 个人错误日志 + 可听见的进步证据（同题录音对比与真实指标曲线）**"为核心的口语软件；学术（文献）线与日常线分开；15 分钟一节；不要假进度、不要刷题化。
