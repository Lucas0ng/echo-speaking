# 词表

`ngsl-spoken-1.2.csv`：NGSL-Spoken 1.2，最常用的 721 个口语词。每行一个词：第一个是原形，后面是它的变形（复数、三单、过去式等）。来自官方页面 <https://newgeneralservicelist.com/ngsl-spoken> 的「alphabetized and lemmatized for teaching」版本，只把换行符改成了 Unix 格式，内容没动。

许可和出处：New General Service List-Spoken by Browne, C. and Culligan, B., is licensed under a [Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/). Browne, C., Culligan, B. (2013). The New General Service List - Spoken. Retrieved from http://www.newgeneralservicelist.com

课程内容用 `tools/check_vocab.py` 对照这份词表检查。
